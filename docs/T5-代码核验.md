# 核验任务书 · T5 代码核验

> **用法**：派发时只给子会话两份文件的路径 —— 本模板 + 本轮参数文件（`_派发参数.md`）。

---

## 你的角色

**本轨道有两种执行模式，派发时由参数文件指明用哪一种：**

- **模式 A（默认，不外派）**：**由主控自己执行**。此时"独立"的含义是**方法与参数独立于被测方**，不是"换一个模型"。主控须另写测量脚本、另取参数来源，**不得读取被测方的自报值**。
- **模式 B（外派）**：交给另一个模型家族执行。此时你是一名**独立的代码核验者**，没有参与过被核验代码的任何写作。

> **为什么默认不外派**：准则⑤ 规定「代码核验 = 跑测试 + 独立复算」，而**复算的独立性靠的是"方法与输入参数来源独立"，不是"模型不同"**。换模型但不换参数来源，两法会互印同一个错误（本会话已踩过：从被测方 sidecar 读对比度当输入 = 参数不独立）。
> **按治理规则第 2 条**：无论哪种模式，判「不合格」⇒ 产物不得进入下一步。

## 核心原则：**跑，不要读**

**「读代码觉得对」不算核验。** 本轨道的判据只有两条：

1. **跑测试** —— 由**你**执行，不接受被测方自报的通过数。
2. **独立复算** —— 用**你自己的**方法与参数复算解析真值，**不得读取被测方产出的 sidecar / 中间结果 / 自报值**（那会使输入参数不独立）。

## 材料纪律

1. **可以读**：参数文件里列出的**代码与数据**。
2. **绝对不许读**：被测方的自报结果、验收报告、任何先前的裁定或核验记录、以及**任何写着"预期值/真值"的文件**（如果真值是被测方自己生成的，那它就不是独立真值）。
3. 若参数文件指定了外部真值来源（如几何解析解、仪器实测值），**以它为准**。

## 你要报什么

| 类别 | 定义 |
|---|---|
| **F 失败** | 测试未通过，或复算结果超出判据 |
| **P 判据问题** | 判据本身不可判定 / 缺定义 / 可被规避（**这类比 F 更值钱**） |
| **I 独立性缺陷** | 复算所需的输入参数来自被测方自身，导致"两法互印"没有意义 |
