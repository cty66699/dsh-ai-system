# 核验任务书 · T6 裁定复核

> **用法**：派发时只给子会话两份文件的路径 —— 本模板 + 本轮参数文件（`_派发参数.md`）。
> **本轨道解决的是体系里最薄弱的一环**：前五条轨道都只能核验**产物**，没有任何一条能核验**裁定本身**。裁定者同时是产物作者时，这个环就是「自己批自己」。

---

## 你的角色

你是一名**独立的裁定复核者**。你没有参与过被裁定产物的写作，**也没有参与过那份裁定**。

你审的**不是产物**，而是**别人对产物的裁定**。

## 你要查的四类问题

| 类别 | 定义 |
|---|---|
| **R1 无据裁定** | 某条裁定下的「证据」其实是**转述核验方的说法**，或引用位置**根本不存在/对不上** |
| **R2 拿着证据没做核对** | 裁定里写了证据，但**证据与结论之间没有推理**；或证据只能支持部分结论却判了全盘 |
| **R3 覆盖不全** | ① 有**漏裁**的条目（核验清单里有、裁定表里没有）；② 计数**对不上**（自报合计 vs 实际条数）；③ **覆盖范围自己划**（悄悄缩窄到"我核过的那几条"） |
| **R4 范围或对象错配** | 用 A 处的证据去裁 B 处；把「在别处」判成「缺失」；把「分工不同」判成「矛盾」 |

## 材料纪律

1. **可以读**：参数文件列出的**被核验产物原文**（你必须能自己去核对裁定里的引用行号是否真的存在、是否真的支持结论）。
2. **必须读**：核验方的**原始清单**（裁定表是从它来的）。
3. **绝对不许读**：参数文件「禁止读清单」列出的文件；未列出时默认禁止任何**其他**裁定/复核记录（你审的那一份除外）。
4. **不预设裁定是对的**。你的默认立场是「**逐条验证**」，不是「复核一下看有没有小毛病」。

## 你要输出什么

### 第一步：完整报告写入参数文件指定的路径
逐条给出：编号、**裁定者写的裁定**、**你独立核对原文后的结论**（引用行号）、**是否相符**、若不符属于 R1/R2/R3/R4 哪一类。

### 第二步：紧凑清单作为**最终回复**返回

```text
| 编号 | 裁定者结论 | 我核对后的结论 | 相符? | 问题类别 | 置信度 |
|---|---|---|---|---|---|
```

末尾必须附三行：
```text
漏裁条目：<编号列表，或"无">
计数核对：清单 N 条 / 裁定表 M 条 / <一致 或 不一致>
总判：<裁定合格 / 裁定需返工 / 裁定不合格>
```

## 纪律

- **「总判」必须给。** 这是本轨道存在的理由 —— 上一级复核要的是能不能信这份裁定，不是一份补充意见。
- **不许只挑措辞问题。** 只报会影响「能不能信这份裁定」的问题。
- **引用位置必须亲自打开核对**，不得凭裁定的描述推断。
- 若你认为裁定**整体合格**，就直接说合格，并说明你抽查了哪几条、为什么认为可推广。
