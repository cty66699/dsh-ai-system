## 收敛账

> **治理规则：计数必须对得上。** 本表的「标称条数」由 _check_counts.cjs 与右列的实际编号数逐行核对。

| **状态** | **条数** | 编号 |
|---|---|---|
| **已修** | **2** | R-1 R-2 |
| **部分修** | **0** | |
| **未修** | **0** | |
| **已驳回** | **0** | |

> **读法**：这里只列**编号**，不写说明 —— 说明写在上面的逐条裁定表里。
> 脚本数的是"这一格里有几个编号"，所以**别在格子里写"与 R-1 绑定"这种话**（它会把被提到的编号也算进去）。

**合计：A=2 B=0 C=0**

> **这一行为什么必须有**：`_check_counts.cjs` 靠它做**外部对账**（收敛账实际数 vs 报告自报数）。
> 缺了它，脚本会报「**无法对账**」并**判非 0** —— 因为「无法对账」不等于「对账通过」，
> 此时报绿就等于发了一个**假绿**。A/B/C 的语义由你的核验报告定义（本示例里 A = 发现总数）。
> **也可以把它写进第二个参数（核验方清单）里** —— 脚本会优先从清单读，读不到才回退到本文件。
